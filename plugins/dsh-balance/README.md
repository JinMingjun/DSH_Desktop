# DeepSeek API 余额

桌面端右上角的 Session 页眉第二行显示 `余额：xxx CNY`，与上方整个“Session 日志”按钮居中对齐，字号与“对话 / 轨迹”标签一致。页面可见时每 15 秒查询一次，切回窗口时也会更新；失败时显示 `余额：-- CNY`，鼠标悬停可查看原因。

桌面宿主使用启动时继承的 `DEEPSEEK_API_KEY` 向 DeepSeek 官方 `GET /user/balance` 接口查询。密钥只在 .NET 宿主中读取，不传到 WebView 页面。请在启动桌面端之前配置此环境变量；只在 DSH 凭据文件或模型设置中保存密钥不足以供此插件查询。若当前 DSH 改用其他凭据名或第三方 API 地址，此插件需要相应调整。
