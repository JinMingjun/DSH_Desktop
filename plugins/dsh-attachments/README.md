# dsh-attachments

DSH Desktop 附件选择插件：回形针打开 Windows 多选文件窗口，文件卡片与输入框左右对齐，自动换行，支持逐项移除。

## 数据流程

1. `window.dshDesktop.pickFiles()` 请求桌面端显示 `OpenFileDialog`。
2. 文档等文件只返回路径、名称和大小；客户端通过独立的 `dsh-attachments` 引用源加入 DSH 草稿，提交时序列化为 `@path` 或 `@"含空格的路径"`。
3. 图片返回实际字节，转换为浏览器 `File` 后调用 DSH 原生图片附件接口。

文档卡片在输入框上方显示，其对应的编辑器引用不重复显示；手动输入的普通 `@` 引用保留原有显示。草稿仍参与 DSH 的发送、撤销和失败恢复流程，刷新时利用 `dsa:draft:<sessionId>` 元数据恢复文档卡片。图片沿用 DSH 自身的预览和草稿生命周期。

## 限制

- 单次最多选择 32 个文件。
- PNG/JPEG/WebP/GIF 单张上限 20 MB，每批图片总量上限 64 MB；同时遵守当前模型更严格的图片限制。
- 文件类型不做白名单限制，但文档、表格、演示文稿、音视频等能否读取由 DSH 工具决定，插件不转换格式。
- 需要桌面端消息桥；普通浏览器不会显示原生附件选择入口。
- 按会话隔离选择结果；切换/关闭会话或开始提交后，过期的选择结果不会加入其他草稿。

## 验证

从仓库根目录运行 `node --test tests/attachments.test.cjs`。已覆盖路径编码、多选去重、引用序列化、草稿恢复、移除位置、图片限制、过期会话和插件清单合并。
